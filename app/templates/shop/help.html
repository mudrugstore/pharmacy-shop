พรีออเดอร์ของฉันดูประวัติการสั่งจองและสถานะ

1. สมัครสมาชิก

  1. กด สมัครสมาชิก (มุมขวาบน)
  2. กรอก ชื่อ, เบอร์โทร (ขึ้นต้น 0 มี 9-10 หลัก), รหัสผ่าน (อย่างน้อย 6 ตัว) และยืนยันรหัสผ่าน
  3. กด สมัครสมาชิก แล้วเข้าสู่ระบบ

หมายเหตุ: 1 เบอร์โทรสมัครได้ 1 บัญชี และเบอร์โทรใช้เป็นชื่อผู้ใช้สำหรับเข้าสู่ระบบ

2. เลือกซื้อสินค้า

  1. ที่หน้า สินค้าทั้งหมด กดหมวดหมู่ด้านบนเพื่อกรอง หรือกด "ทั้งหมด" เพื่อดูทุกหมวด
  2. พิมพ์ชื่อสินค้าในช่องค้นหาด้านบนเพื่อค้นหา
  3. กดการ์ดสินค้าเพื่อดูรายละเอียด

3. สั่งซื้อสินค้า

  1. ในหน้ารายละเอียดสินค้า เลือกจำนวน แล้วกด เพิ่มลงตะกร้า
  2. กดไอคอน ตะกร้า เพื่อตรวจรายการ (แก้จำนวน/ลบได้)
  3. ใส่หมายเหตุถึงร้าน (ถ้ามี) แล้วกด ยืนยันคำสั่งซื้อ
  4. ระบบจะแจ้งให้ ติดต่อชำระเงินที่ร้าน

ระบบนี้ไม่มีการชำระเงินออนไลน์ หลังสั่งซื้อให้ติดต่อร้านเพื่อชำระเงิน

4. สั่งจองพรีออเดอร์

  1. กดเมนู พรีออเดอร์ เลือกสินค้าและจำนวน
  2. กด สั่งจอง ทางร้านจะติดต่อกลับตามเบอร์โทรที่ลงทะเบียนไว้

5. ดูประวัติ

เมนู คำสั่งซื้อของฉัน และ พรีออเดอร์ของฉัน แสดงรายการและสถานะทั้งหมด

6. ลืมรหัสผ่าน

  1. ติดต่อร้าน (โทรตามเบอร์บนเว็บ) แจ้งว่าลืมรหัสผ่าน
  2. แอดมินจะรีเซ็ตรหัสให้
  3. เข้าสู่ระบบด้วยเบอร์โทรของคุณ ระบบจะบังคับให้ตั้งรหัสผ่านใหม่ทันที

สำหรับผู้ดูแลระบบ

เมนูที่ใช้งานได้ (แผงแอดมิน)

เมนูหน้าที่
ภาพรวมดูสถิติรวมของร้าน
หมวดหมู่เพิ่ม/ลบหมวดหมู่ + ใส่รูปหมวดหมู่
สินค้าเพิ่ม/แก้ไข/ลบสินค้า + จัดการสต็อก + อัปโหลดรูป
คำสั่งซื้อดูคำสั่งซื้อแบบละเอียด + อัปเดตสถานะ
พรีออเดอร์ดูรายการสั่งจอง + เบอร์ลูกค้า + อัปเดตสถานะ
ผู้ใช้ดูรายชื่อลูกค้า + รีเซ็ตรหัสผ่าน + ลบผู้ใช้
แบนเนอร์จัดการแบนเนอร์โฆษณาบนหน้าร้าน
ตั้งค่าร้านแก้ชื่อร้าน เบอร์ โลโก้ สีเว็บ ข้อความต่างๆ

1. จัดการหมวดหมู่

เมนู หมวดหมู่ → กรอกชื่อ + เลือกรูปไอคอน (ไม่ใส่ก็ได้) → กด เพิ่มหมวดหมู่ · ลบได้ด้วยปุ่มลบ

2. จัดการสินค้า

  1. เมนู สินค้า → + เพิ่มสินค้าใหม่
  2. กรอก ชื่อ, หมวดหมู่, รายละเอียด, ราคา, สต็อก, รูปสินค้า
  3. ติ๊ก "เป็นสินค้าพรีออเดอร์" ถ้าต้องการให้สินค้าอยู่ในเมนูพรีออเดอร์ (สั่งจอง) แทนการขายปกติ
  4. ตั้งสต็อกเร็ว: ปรับตัวเลขในหน้ารายการสินค้าแล้วกด "ตั้ง"

3. จัดการคำสั่งซื้อ

เมนู คำสั่งซื้อ → กด "รายละเอียด" เพื่อดูข้อมูลลูกค้า เบอร์โทร และรายการสินค้า → เลือกสถานะแล้วกดบันทึก

เมื่อลูกค้าสั่งซื้อ ระบบตัดสต็อกอัตโนมัติทันที

4. จัดการพรีออเดอร์

เมนู พรีออเดอร์ → เห็นเบอร์ลูกค้าสำหรับติดต่อกลับ → อัปเดตสถานะ (รอติดต่อกลับ / ติดต่อแล้ว / ยืนยันแล้ว / ยกเลิก)

5. จัดการผู้ใช้

เมนู ผู้ใช้ → กรณีลูกค้าลืมรหัส กด "รีเซ็ตรหัส" ลูกค้าจะต้องตั้งรหัสใหม่เองเมื่อเข้าสู่ระบบครั้งถัดไป · ลบผู้ใช้ได้ (ย้อนกลับไม่ได้)

6. จัดการแบนเนอร์

  1. เมนู แบนเนอร์ → เลือกรูป (แนะนำ 1200 x 384 px)
  2. เลือกหน้าที่จะแสดง: ทั้งสองหน้า / หน้าสินค้า / หน้าพรีออเดอร์
  3. ใส่ลิงก์เมื่อคลิก (ไม่ใส่ก็ได้) และลำดับการแสดง → อัปโหลด
  4. ซ่อน/แสดง หรือลบได้ที่การ์ดแบนเนอร์

7. ตั้งค่าร้าน

เมนู ตั้งค่าร้าน → แก้ โลโก้, ชื่อร้าน, เบอร์โทร, ที่อยู่, เวลาทำการ, ข้อความแจ้งลูกค้า และ สีหลักของเว็บ (เปลี่ยนแล้วมีผลทันที)

เริ่มใช้งานครั้งแรก

  1. ตั้งค่าร้าน (ชื่อ เบอร์ โลโก้ สี)
  2. สร้างหมวดหมู่
  3. เพิ่มสินค้าพร้อมรูปและสต็อก
  4. (ถ้าต้องการ) อัปโหลดแบนเนอร์
  5. ทดสอบฝั่งลูกค้า: สมัครบัญชีทดสอบ ลองสั่งซื้อ แล้วดูที่เมนูคำสั่งซื้อ
