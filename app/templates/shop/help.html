เมนูที่ลูกค้าใช้งานได้

เมนูหน้าที่
สินค้าทั้งหมดดู เลือกซื้อ ค้นหา และเรียงลำดับสินค้า
พรีออเดอร์ดูและสั่งจองสินค้าที่เปิดให้จองล่วงหน้า

ช่วยเหลือคู่มือการใช้งาน (หน้านี้)

1. สมัครสมาชิก และ เข้าสู่ระบบ

  1. กด สมัครสมาชิก (มุมขวาบน)
  2. กรอก ชื่อ, เบอร์โทร (ขึ้นต้น 0 มี 9-10 หลัก), รหัสผ่าน (อย่างน้อย 6 ตัว) และยืนยันรหัสผ่าน
  3. กด สมัครสมาชิก เสร็จแล้วเข้าสู่ระบบด้วยเบอร์โทร + รหัสผ่าน

1 เบอร์โทรสมัครได้ 1 บัญชี · เบอร์โทรใช้เป็นชื่อผู้ใช้สำหรับเข้าสู่ระบบ

2. ค้นหา เลือกดู และเรียงลำดับสินค้า

  1. หน้า สินค้าทั้งหมด กด หมวดหมู่ ด้านบนเพื่อกรองเฉพาะหมวดที่สนใจ (กด "ทั้งหมด" เพื่อดูทุกหมวด)
  2. พิมพ์ชื่อสินค้าใน ช่องค้นหา ด้านบนแล้วกดค้นหา
  3. ใช้ เมนูเรียงลำดับ (มุมขวาของแถบสินค้าแนะนำ) เลือก: ล่าสุด / เก่าสุด / ราคาต่ำ-สูง / ราคาสูง-ต่ำ / ชื่อ
  4. กดการ์ดสินค้าเพื่อดูรายละเอียดแบบ popup (ไม่เปลี่ยนหน้า)

ป้ายมุมการ์ด: "สินค้าหมด" = หมดสต็อก, ป้ายอื่นๆ เป็นข้อความที่ร้านตั้งไว้

3. เพิ่มลงตะกร้า และ สั่งซื้อ

  1. กดการ์ดสินค้า → เลือกจำนวน → กด เพิ่มลงตะกร้า (มีภาพเคลื่อนไหวของเข้าตะกร้า ไม่เปลี่ยนหน้า เลือกชิ้นอื่นต่อได้ทันที)
  2. กดไอคอน ตะกร้า มุมขวาบน → ปรับจำนวนด้วยปุ่ม − / + (ยอดรวมอัปเดตทันที) หรือกด ✕ เพื่อลบ
  3. ใส่หมายเหตุถึงร้าน (ถ้ามี) เช่น ที่อยู่จัดส่ง แล้วกด ยืนยันคำสั่งซื้อ
  4. ระบบแจ้งให้ ติดต่อชำระเงินที่ร้าน (ไม่มีการชำระเงินออนไลน์)

4. สั่งจองพรีออเดอร์

  1. กดเมนู พรีออเดอร์ เลือกสินค้าและจำนวน
  2. กด สั่งจอง — ทางร้านจะติดต่อกลับตามเบอร์โทรที่ลงทะเบียนไว้

5. ติดตามและยกเลิกรายการ

  1. เมนู คำสั่งซื้อของฉัน / พรีออเดอร์ของฉัน แสดงรายการและสถานะทั้งหมด
  2. ยกเลิกเองได้ ถ้าสถานะยังเป็น "รอดำเนินการ" (คำสั่งซื้อ) หรือ "รอติดต่อกลับ" (พรีออเดอร์) โดยกดปุ่ม ยกเลิก
  3. ถ้าทางร้านเริ่มดำเนินการแล้ว จะยกเลิกเองไม่ได้ ต้องติดต่อร้านโดยตรง

เวลาที่แสดงทุกหน้าเป็นเวลาประเทศไทย (GMT+7)

6. ลืมรหัสผ่าน

  1. ติดต่อร้าน (โทรตามเบอร์บนเว็บ) แจ้งว่าลืมรหัสผ่าน
  2. แอดมินจะรีเซ็ตรหัสให้
  3. เข้าสู่ระบบด้วยเบอร์โทรของคุณ ระบบจะบังคับให้ ตั้งรหัสผ่านใหม่ ทันทีก่อนใช้งานต่อ

จัดการร้านค้าทั้งหมดผ่านแผงแอดมิน เข้าได้จากเมนู "แผงแอดมิน" บนแถบด้านบน

เมนูในแผงแอดมิน

เมนูหน้าที่
ภาพรวมดูสถิติรวม (คลิกการ์ดไปหน้าที่เกี่ยวข้องได้)
หมวดหมู่เพิ่ม/แก้ชื่อ/เปลี่ยนรูป/ลบ หมวดหมู่
สินค้าเพิ่ม/แก้ไข/ลบสินค้า + จัดการสต็อก + แก้หลายรายการพร้อมกัน
คำสั่งซื้อดูรายละเอียด + อัปเดตสถานะ + เห็นรายการที่ลูกค้ายกเลิก
พรีออเดอร์ดูคำขอ + เบอร์ลูกค้า + อัปเดตสถานะ
ผู้ใช้ดูรายชื่อ + รีเซ็ตรหัสผ่าน + ลบผู้ใช้
แบนเนอร์จัดการแบนเนอร์โฆษณา (เลือกหน้าที่แสดง)
ตั้งค่าร้านชื่อร้าน เบอร์ โลโก้ สีเว็บ ข้อความต่างๆ

1. ภาพรวม (Dashboard)

แสดงจำนวนสินค้า หมวดหมู่ คำสั่งซื้อ พรีออเดอร์ที่รอติดต่อ และผู้ใช้ — คลิกการ์ดใดก็ได้เพื่อไปยังหน้านั้นทันที

2. จัดการสินค้า

สินค้าแสดงเป็นการ์ด (ค้นหาได้จากช่องด้านบน) แต่ละการ์ดบอกสถานะสต็อกด้วยสี: ปกติ ใกล้หมด หมด

  1. เพิ่มสินค้า: กด "+ เพิ่มสินค้าใหม่" กรอกชื่อ หมวดหมู่ ป้ายมุมการ์ด รายละเอียด ราคา สต็อก รูป และติ๊ก "พรีออเดอร์" ถ้าต้องการให้เป็นสินค้าสั่งจอง
  2. แก้ไขทีละรายการ: กดปุ่ม "แก้ไข" ที่การ์ด → แก้ใน popup (ไม่เปลี่ยนหน้า) → บันทึก
  3. แก้ไขหลายรายการพร้อมกัน: กดปุ่ม "แก้ไขหลายรายการ" → แก้ชื่อ/ราคา/สต็อก/พรีออเดอร์ ของหลายสินค้าในตารางเดียว → กด "บันทึกทั้งหมด" ครั้งเดียว
  4. ลบสินค้า: กดปุ่ม "ลบ" ที่การ์ด

ป้ายมุมการ์ด: พิมพ์ข้อความเองได้ (เช่น "ยา", "ใหม่", "ลดราคา") แต่ถ้าสินค้าหมดสต็อก ระบบจะแสดง "สินค้าหมด" แทนเสมอ

3. จัดการหมวดหมู่

  1. เพิ่ม: กรอกชื่อ + เลือกรูปไอคอน (ไม่ใส่ก็ได้) → กด "เพิ่มหมวดหมู่"
  2. แก้ไข: แต่ละหมวดเป็นการ์ด — คลิกที่รูปเพื่อเปลี่ยนรูป และแก้ชื่อในช่องได้เลย → กด "บันทึก"
  3. ลบ: กดปุ่ม "ลบ" (สินค้าในหมวดที่ถูกลบจะกลายเป็นไม่มีหมวดหมู่ แต่ไม่ถูกลบ)

4. จัดการคำสั่งซื้อ

  1. เมนู คำสั่งซื้อ → กด "รายละเอียด" เพื่อดูข้อมูลลูกค้า เบอร์โทร หมายเหตุ และรายการสินค้า
  2. เลือกสถานะ (รอดำเนินการ / กำลังเตรียมของ / พร้อมรับ-จัดส่ง / ชำระเงินแล้ว / เสร็จสิ้น / ยกเลิก) แล้วกด "บันทึกสถานะ"
  3. รายการที่ ลูกค้ายกเลิกเอง จะขึ้นสถานะ "ยกเลิกโดยลูกค้า" (สีแดง) และระบบคืนสต็อกให้อัตโนมัติแล้ว

เมื่อลูกค้าสั่งซื้อ ระบบตัดสต็อกทันที · เมื่อยกเลิก ระบบคืนสต็อกทันที

5. จัดการพรีออเดอร์

เมนู พรีออเดอร์ → เห็นเบอร์ลูกค้าสำหรับโทรติดต่อกลับ → อัปเดตสถานะ (รอติดต่อกลับ / ติดต่อแล้ว / ยืนยันแล้ว / ยกเลิก) · รายการที่ลูกค้ายกเลิกเองจะขึ้น "ยกเลิกโดยลูกค้า"

6. จัดการผู้ใช้

เมนู ผู้ใช้ → กรณีลูกค้าลืมรหัส กด "รีเซ็ตรหัส" (ลูกค้าจะต้องตั้งรหัสใหม่เองเมื่อเข้าสู่ระบบครั้งถัดไป — แอดมินไม่เห็นรหัสลูกค้า) · ลบผู้ใช้ได้ (ย้อนกลับไม่ได้)

7. แบนเนอร์โฆษณา

  1. เมนู แบนเนอร์ → เลือกรูป (แนะนำแนวนอน ~1200 x 384 px)
  2. เลือก หน้าที่จะแสดง: ทั้งสองหน้า / หน้าสินค้า / หน้าพรีออเดอร์
  3. ใส่ลิงก์เมื่อคลิก (ไม่ใส่ก็ได้) และลำดับการแสดง → อัปโหลด
  4. ซ่อน/แสดง หรือลบได้ที่การ์ดแบนเนอร์ · ถ้ามีหลายรูปจะเลื่อนสไลด์อัตโนมัติ

8. ตั้งค่าร้าน

เมนู ตั้งค่าร้าน → แก้ โลโก้, ชื่อร้าน, เบอร์โทร, ที่อยู่, เวลาทำการ, ข้อความแจ้งลูกค้า และ สีหลักของเว็บ (เลือกสีแล้วทั้งเว็บเปลี่ยนตาม) — บันทึกแล้วมีผลทันที

เริ่มใช้งานครั้งแรก (แนะนำตามลำดับ)

  1. ตั้งค่าร้าน (ชื่อ เบอร์ โลโก้ สี)
  2. สร้างหมวดหมู่สินค้า
  3. เพิ่มสินค้าพร้อมรูปและสต็อก
  4. (ถ้าต้องการ) อัปโหลดแบนเนอร์โฆษณา
  5. ทดสอบฝั่งลูกค้า: สมัครบัญชีทดสอบ ลองสั่งซื้อ แล้วกลับมาดูที่เมนูคำสั่งซื้อ
